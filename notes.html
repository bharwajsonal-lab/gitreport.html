Git Commands Notes

What is Git?

Git is a version control system that helps developers track and manage changes to source code during development. It's widely used for collaborative software development.

Initialization & Configuration

CommandDescription
git initInitialize a new Git repository.
git config --global user.name "Your Name"Set your Git username.
git config --global user.email "you@example.com"Set your Git email.
git config --listView Git configuration settings.

Basic Git Workflow

CommandDescription
git statusCheck current changes and status.
git add <file>Stage a file for commit.
git add .Stage all files for commit.
git commit -m "message"Commit staged changes with a message.
git logShow commit history.

Remote Repositories

CommandDescription
git remote add origin <url>Link to a remote repository.
git push -u origin mainPush local commits to remote main branch.
git clone <url>Clone a repository.
git pullFetch and merge changes from remote.

Branching

CommandDescription
git branchList all branches.
git branch <name>Create a new branch.
git checkout <name>Switch to a branch.
git checkout -b <name>Create and switch to a branch.
git merge <name>Merge a branch into current branch.

Undoing Changes

CommandDescription
git reset <file>Unstage a file.
git reset --hardDiscard all changes (use with caution).
git revert <commit-id>Undo a specific commit safely.
